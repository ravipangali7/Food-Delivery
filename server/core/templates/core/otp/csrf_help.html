Why you may see “CSRF cookie not set” or 403 on POST /api/…

Cross-site request protection expects a matching security cookie and token on unsafe browser requests when using session login across different origins. A web app on http://localhost:8080 calling http://api.shyam-sweets.com does not automatically receive that cookie, so POST requests can fail.

Our API uses token authentication by default. Send Authorization: Token <key> after login. Session cookies are only needed for same-origin HTML forms such as this OTP page.

This OTP page is served on the same origin as the form and includes a valid security token, so the browser can submit without extra setup.
